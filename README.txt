HOSTEL MANAGEMENT SYSTEM

RUN:
1. Install Node.js LTS.
2. Open PowerShell/Terminal INSIDE this folder (the folder containing package.json).
3. Run: npm install
4. Run: npm start
5. Open http://localhost:3000

IMPORTANT: If your prompt says C:\Users\user\Desktop\college>, first use cd to enter the extracted hostel-management-system folder.

ADMIN LOGIN: admin / admin123
STUDENT LOGIN: STU001 / student123

SQLite database hostel.db is created automatically on first run.
Tables: students, rooms, fees, complaints, mess.


ATTENDANCE: Administrator login is required to add/edit attendance. Students can only view their own attendance and attendance percentage.
